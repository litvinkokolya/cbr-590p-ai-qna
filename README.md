# CBR 590-P AI Q&A

Чат-бот для ответов на вопросы по Положению Банка России [№ 590-П](https://www.consultant.ru/document/cons_doc_LAW_220089/) «О порядке формирования кредитными организациями резервов на возможные потери по ссудам».

Реализован на **LangGraph** с использованием **RAG** (векторный поиск по тексту 590-П) и механизма **Human-in-the-Loop (HITL)** для уточнения неполных запросов.

---

## Возможности

- Отвечает на вопросы по 590-П на основе векторного поиска по тексту документа
- При неполном запросе задаёт уточняющие вопросы (HITL)
- Поддерживает многошаговые уточнения — продолжает переспрашивать пока не получит достаточно данных
- Ссылается на конкретные пункты положения в ответах

---

## Схема графа

```
[START]
   ↓
[parse_request]         — инициализация state
   ↓
[check_completeness]  ←─────────────────────┐
   ↓                                         │
   ├── данных не хватает → [ask_human]       │
   │                          ↓ interrupt()  │
   │                     ждёт ответа         │
   │                     пользователя        │
   │                          └─────────────►┘
   │
   └── данных достаточно → [retrieve]
                               ↓
                         RAG поиск по 590-П
                               ↓
                        [generate_answer]
                               ↓
                             [END]
```

### Логика работы

1. `parse_request` — инициализирует поля state при каждом новом вопросе
2. `check_completeness` — LLM анализирует историю диалога и определяет, достаточно ли данных для точного ответа. Если нет — формулирует уточняющий вопрос
3. `ask_human` — останавливает граф через `interrupt()` и ждёт ответа пользователя. После получения ответа управление возвращается в `check_completeness` (петля)
4. `retrieve` — выполняет семантический поиск по FAISS-индексу 590-П, возвращает топ-8 релевантных чанков
5. `generate_answer` — LLM генерирует ответ строго на основе найденных чанков, со ссылками на пункты положения

## Структура проекта

```
cbr-590p-ai-qna/
│
├── main.py               — точка входа, CLI-цикл с поддержкой HITL
│
├── src/                  — исходный код агента
│   ├── graph.py          — сборка LangGraph графа, подключение MemorySaver
│   ├── nodes.py          — все узлы графа и routing-функция
│   ├── state.py          — TypedDict State со всеми полями диалога
│   ├── prompts.py        — системные промпты для LLM
│   └── rag.py            — индексация 590-П и инициализация FAISS retriever
│
├── data/                 — данные
│   ├── 590-п.docx        — исходный текст Положения ЦБ РФ № 590-П
│   └── faiss_590p_index/ — готовый векторный индекс (FAISS)
│       ├── index.faiss   — векторы эмбеддингов всех чанков
│       └── index.pkl     — маппинг векторов на исходные тексты чанков
│
├── tests/
│   ├── test_nodes.py     — юнит-тесты каждого узла графа (с моками LLM)
│   └── test_graph.py     — интеграционные тесты полного графа (полный вопрос и HITL)
│
├── pyproject.toml        — конфигурация ruff и pytest
├── requirements.txt      — зависимости проекта
└── .env                  — переменные окружения (не в репозитории)
```

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/litvinkokolya/cbr-590p-ai-qna.git
cd cbr-590p-ai-qna
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv venv
source venv/Scripts/activate  # Windows
pip install -r requirements.txt
```

### 3. Добавить API ключ

Создать файл `.env` в корне проекта:

```
OPENAI_API_KEY=sk-...
```

### 4. Запустить чат-бот

```bash
python main.py
```

FAISS-индекс уже включён в репозиторий — переиндексация не требуется.

## Примеры диалога

**Неполный запрос — агент уточняет:**
```
Вы:    По сделке качество обслуживания долга плохое. Какую минимальную ставку резерва я могу использовать?
Агент: Укажите категорию качества ссуды (I-V) и тип заёмщика.
Вы:    III категория, юридическое лицо, обеспечения нет.
Агент: Согласно п. 3.11 Положения 590-П, для ссуд III категории качества (сомнительные)
       размер расчётного резерва составляет от 21% до 50% от суммы основного долга...
```

**Полный вопрос — агент отвечает сразу:**
```
Вы:    Какой размер резерва для стандартных ссуд I категории качества?
Агент: Согласно таблице 2 п. 3.11, для ссуд I категории качества (стандартные)
       размер расчётного резерва составляет 0%...
```
